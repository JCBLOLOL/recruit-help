# Recruit Help

Student passion project — recruiting profiles for baseball and softball athletes.

**Live site (after Vercel deploy):** `https://recruit-help.vercel.app` (or your Vercel URL)

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- [Next.js](https://nextjs.org) (App Router)
- [Tailwind CSS](https://tailwindcss.com)
- Vercel (hosting)
- Supabase (coming in M1 — auth + database)

## Deploy to Vercel

1. Push this repo to GitHub (`JCBLOLOL/recruit-help`).
2. In Vercel → **Add New Project** → import `recruit-help`.
3. Click **Deploy** (defaults are fine for Next.js).
